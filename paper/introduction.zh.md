Agent 在辅助研究者发现相关工作、比较研究方案和准备实验时，需要综合利用论文及其关联材料中的研究知识。一项研究的问题、方法、实验设置与结果分布在正文、图表和附录中，实现与评测细节还可能由配套材料补充；不同研究又通过引文、共享资源和方法沿用建立联系。Agent 要据此作出有依据的判断，需要理解各部分内容的含义，以及它们在具体研究中的对应关系。

这些材料主要围绕研究的论证与报告组织，研究主张、支撑证据和适用条件之间的联系并不总以可独立访问的知识记录显式表达。例如，判断某种方法能否用于当前问题，可能需要将正文中的方法描述、表格中的实验结果、附录中的设置和配套材料中的实现相互对照。即使已经找到相关内容，Agent 仍需确认它们是否对应同一实验、结论依赖哪些条件，以及这些依据是否足以支持当前选择。这种跨内容、跨材料的理解与核查，构成了从已有研究到后续研究行动之间需要完成的知识整理工作。

我们由此关注：**如何将论文及其关联材料转化为 Agent 可按需访问、核查和复用的知识产物？** 这种产物需要将问题定义、方法、实验条件、研究结论及关联资源组织为具有明确语义的记录，并保留它们之间的关系、来源证据与适用边界。Agent 可以据此发现候选、比较研究、选择材料，也能够在依据不足时返回原始来源继续检查。我们将这种面向 Agent 使用的研究产物称为 **agent-ready artifacts**。

计算机科学为研究这一转化过程提供了合适的实证场景。预印本与公开发表渠道便于获取新近研究，明确的任务定义、方法描述和实验设置为内容解析提供线索，公开配套材料则为检查实现与评测过程提供了进一步依据。在具有这些条件的研究中，代码库、数据集和 benchmark 提供了实现细节、数据构造与评测协议等可核查信息，可以与论文中的论述相互参照。因此，我们选择计算机科学中具有公开配套材料的论文作为初始实证范围，利用其材料可访问、研究对象及其关系可追踪的条件，考察如何构建和核查面向 Agent 的研究知识。即使这些材料已经公开，它们是否对应同一项实验、某项结论依赖什么条件，以及已有用法能否支持新需求，仍需跨材料理解与判断。

```text
**案例：`<某 query>`。** 考虑 Agent 接到研究者提出的这一需求，需要调研相关工作，并为验证想法准备材料。随着候选和证据的积累，Agent 需要回答以下相互关联的问题：

- **Q1：发现。** 哪些论文与这一研究需求相关，哪些值得优先阅读？
- **Q2：判断。** 看起来相关的候选是否满足需求条件？它们的问题定义、方法和实验设置有什么区别？
- **Q3：选择。** 哪些 benchmark 和数据适合检验这一想法，已有研究如何使用它们？
- **Q4：准备使用。** 有哪些实现与评测工具可以采用，需要确认哪些版本、配置和使用条件？
```

这个案例将围绕一次有证据支持的选择转折展开。设想初始检索已返回 `<候选论文 A>`；检查 `<论文论述与关联材料中的关键证据>` 后，Agent 发现其方法或评测条件与 `<当前需求>` 存在差异，因而修正对候选的判断。进一步的检查也可能沿资源或引用关系引入 `<候选论文 B>`。具体转折将由真实材料确定，需要展示哪些知识改变了选择，以及这些知识如何从论文与关联材料中获得。

在这一过程中，用于回答 Q3 的任务样例或评分代码可能改变 Q2 的判断，Q4 中发现的版本差异可能促使 Agent 调整资源选择，关联材料也可能重新打开 Q1 的发现过程。Agent 因而需要将论文内容与材料证据联系起来，形成可支撑行动的理解。当其他研究需求涉及同一篇论文或同一资源时，其中的问题定义、使用记录和实验条件具有复用价值；新需求下的适用性则需要结合这些事实重新判断。逐次从原始材料中恢复这些知识，会产生重复检索、阅读和推理的成本，这也促使我们研究能够持久保存、按需访问和继续核查的知识组织形式。

构建这样的研究产物面临三项挑战。第一，**形成有证据支持的语义关系。** 论文中的方法、实验条件和结论可能分散在不同位置，相关实现与评测材料又提供了不同层次的细节。对案例中的 Q2 和 Q3，系统需要确认某个资源用于哪项实验、采用了什么设置、对应哪些结果，防止将分别正确的信息拼接为不成立的关系。作者的概括性描述、特定实验中的实际用法，以及当前需求下的适用性，需要分别表达，并保留无法确认的内容。

第二，**组织能够服务不同研究行动的知识单元及其联系。** Q1–Q4 需要的信息粒度不同：发现可能从问题或方法出发，判断需要条件与证据，准备使用则需要更具体的版本和配置。面向 Agent 的组织形式需要明确哪些内容可以独立访问、哪些关系必须一起保留，以及如何从一条记录追溯到论文和关联材料。跨论文整合还需要区分同名资源的不同版本与用法，使已有知识能够支持后续检索和比较。

第三，**保留可核查复用所需的边界。** 一条记录是否足以支持当前行动，取决于其来源、版本、检查范围和研究需求。论文声称发布代码、观察到仓库内容、成功执行程序与复现实验是不同的发现。组织形式需要表达这些证据状态，使 Agent 能够判断何时可以采用已有记录、何时需要补充检查，并避免将特定条件下的结论当作普遍事实复用。

为此，我们研究 **Papers for Agents（P4A）**，探索面向研究 Agent 的研究产物组织形式及其构建方法。P4A 通过内容解析、语义理解与材料核查等预处理流程，将论文及其公开关联材料中的研究内容整合为有依据、可访问、可复用的知识记录，并以持久化文献资源库承载这些产物。我们关注如何通过推理式抽取建立论文内部及关联材料之间的语义关系，将事实、来源证据、检查状态与适用条件共同组织起来，使 Agent 能够按需获取已有知识，并继续追踪尚未解决的问题。具体记录粒度、组织结构与访问方式仍需围绕明确的任务和证据环境确定。

围绕上述问题，本文拟从三个方面开展工作：

- **面向 Agent 的研究产物组织。** 研究如何表达论文中的研究内容、关联材料及其关系，保留来源、条件和检查状态，支持发现、判断、选择与使用准备。
- **基于推理与核查的产物构建。** 研究如何从论文及关联材料中抽取、对齐和核查语义关系，处理证据不足或不一致的情况，形成能够支持后续研究行动的记录。
- **产物质量与使用价值的评价。** 独立评价产物的语义正确性、关系正确性与证据支持，再考察 Agent 使用这些产物后能否作出更有依据的研究选择，以及知识复用是否减少重复阅读与解释。

我们计划在具有独立核查依据的 CS 论文及关联材料集合上，选择明确的研究任务开展评价。贯穿案例用于展示知识产物如何影响一次具体判断，整组任务用于考察其效果是否能够推广到其他需求。方法比较需要在相同原始材料访问条件和声明的预算下进行，设置直接阅读检索、常规结构化抽取等对照，以区分组织形式、推理与核查带来的作用；开放检索下与外部 DeepResearch 的比较可作为补充，并记录各自的信息范围。构建投入与使用成本将分别报告，通过涉及共享论文和资源的多个需求检验复用价值。具体任务范围、比较协议和质量标准仍待确定。

这项研究旨在探索一种使已发表研究更便于 Agent 发现、理解和利用的组织形式。通过将分散在论文及关联材料中的内容转化为可访问、可追溯、带有适用边界的研究知识，我们希望为 Agent 辅助研究者开展后续工作提供可复用的基础；其有效性需要由产物质量和实际研究行动共同检验。
