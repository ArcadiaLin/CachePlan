Agent 在辅助研究者开展文献调研、撰写综述和设计实验时，需要反复阅读与使用已有论文。论文主要面向人类交流与论证组织，其中的问题、方法、研究条件和结论分布在正文、图表及附录中，部分细节还需要结合关联材料理解。Agent 在阅读过程中，需要将这些内容联系起来，提炼研究发现及其依据，判断它们对当前任务的意义。由此形成的知识，也是后续研究可以继续利用的资源。

这种知识的使用往往跨越多次研究会话。一次调研中整理的方法比较、实验条件和证据，可能在之后的综述写作或方案选择中再次被需要。然而，保存会话记录并不自动使这些知识易于查找和维护：同一论文的阅读成果可能散落在多次回答与独立笔记中，后续修订也未必与原有记录建立联系。新会话中的 Agent 因而需要恢复此前的研究上下文，重新确认结论的含义与依据，甚至重复阅读原始材料。如何使阅读所得知识持续积累，并随研究推进得到补充，是跨会话使用中的一个问题。

研究者还可能在不同 Agent 应用之间切换，分别开展调研、写作或实验。此时，即使阅读成果已经持久保存，消费这些成果的 Agent 仍需理解其组织方式、定位相关研究对象，并确认记录中的条件与证据。例如，调研 Agent 保存的一项方法比较，若没有明确结果所对应的实验条件，写作 Agent 就难以判断哪些比较可以直接引用。后续阅读发现的补充信息，也需要能够写回已有记录并被其他 Agent 继续使用。这要求知识产物具有共同的表示和访问约定，使其含义与维护方式能够独立于原会话和原应用被理解。

上述需求提出了面向 Agent 用户的数据管理问题。以文档和书目记录为中心的学术基础设施，为论文的保存、检索和引用提供了基础；阅读所得知识的积累还需要组织方法、条件、结论及证据之间的关系。已有工作也已探索更丰富的论文知识管理：[AgenticScholar](../references/papers/2026-AgenticScholar-reread/paper.txt) 将知识表示、研究查询规划与算子执行整合在同一系统中，支持多类学术分析。本文关注通用 Agent 作为外部使用者的情形：研究者通过自己的 Agent 决定研究步骤，论文库作为持续存在的数据资源，供不同会话和应用查询、补充与维护。支持这一使用方式，需要明确外部 Agent 共同操作哪些知识对象，以及如何解释和更新这些对象。

我们由此研究：**如何将论文中的研究内容构建为具有共同表示和访问约定的知识产物，使通用 Agent 能够跨任务、跨会话、跨应用发现、引用、补充和复用？** 我们将这种面向 Agent 使用的论文知识产物称为 **agent-ready artifacts**。它们需要保留研究内容的来源、成立条件及相互关系，使后续 Agent 可以理解已有记录，并在证据不足时返回原始材料继续检查。

为此，我们研究 **Papers for Agents（P4A）**，探索面向通用研究 Agent 的论文知识数据库。P4A 关注知识产物的表示模式（artifact schema）及其在不同应用间的互操作（resource interoperability）：Agent 负责研究决策，通过工具访问和管理知识；论文库负责知识的表示、持久保存、关联、查询与更新。产物既可以在预处理时构建，也可以在后续阅读和研究任务中逐步补充。Skill、MCP 等形式可用于接入研究者已有的工作环境，具体接入方式取决于实现与使用需求。

实现这一目标，需要解决知识表示、构建和持续维护之间的联系。首先，一条可复用记录需要明确其描述的研究对象、成立条件和支持证据，避免后续 Agent 将特定实验中的结果理解为普遍结论。其次，不同阅读过程可能对同一对象给出不同描述，新增内容需要区分已有知识的补充、修订，以及不同版本或条件下应当并存的发现。最后，查询和写入操作需要具有明确语义，使消费方能够理解取得的知识及其边界，也使后续写入能够正确延续已有记录。这些问题共同决定了知识产物能否在脱离原会话后被可靠使用。

围绕上述问题，本文拟从三个方面开展工作：

- **面向研究 Agent 的论文知识数据模型与操作语义。** 研究可独立访问、组合使用的知识单元，表达其条件、证据与关联，并定义供外部 Agent 查询和管理的操作语义。
- **论文知识产物的构建与关联管理方法。** 从论文及必要的关联材料中识别研究对象，通过语义理解、证据核查与描述对齐组织知识，支持在保留来源和版本的基础上持续补充与修订。
- **系统实现与跨领域评价。** 实现支持通用 Agent 访问的论文数据库，在计算机科学与经济学中评价产物质量、研究任务效果，以及跨会话、跨 Agent 应用的复用价值与总成本。

评价拟围绕两类应用任务展开：检索与筛选，以及多论文比较与综述。前者考察能否找到符合研究需求的论文并给出有依据的筛选理由；后者考察能否正确比较研究内容，保留重要条件，并用适当证据支持综述中的主张。我们还将独立核查知识单元、关系及其证据支持，覆盖初始构建和后续写入的产物，以检验数据本身的质量。

在这些任务中，我们计划分别考察首次使用、跨会话和跨 Agent 应用的使用条件。跨会话评价将在清除原会话上下文后，提出涉及部分相同论文的新需求；跨应用评价将由不同 Agent 应用交接已有资源，并检查后续写入能否被另一消费方正确使用。比较将在相同原始材料访问条件和声明预算下进行，拟设置直接阅读检索、持久笔记与常规结构化抽取等对照，具体协议待任务范围确定。结果将分别报告各领域、任务和消费 Agent 的质量，以及建库、维护和各次使用的累计成本，从而检验知识积累能否在保持质量的同时减少重复阅读与处理。
