## 三条本项目关心的读法

**(a) 显式推理零增益甚至负增益**

| 对照 | Match Δ | 时间 Δ |
|---|---|---|
| GPT-5 → GPT-5 (High) | **−0.25pp** | +2.16h (+60%) |
| DeepSeek-V3.2 → -Thinking | **−5.18pp** | +3.86h (+74%) |

**(b) 效率与效果同向，不是权衡**
GPT-5：5.50 步 / 6.40M token / 3.58h → 69.16%。
GLM-4.7：81.17 步 / 120.01M token / 8.42h → 19.18%。
步数差 14.8×、token 差 18.8×，准确率是 3.6× 的**反向**差距。

**(c) 每次调用的输入量高度一致**（见 T09）——说明输入成本主体是 ReAct 历史的逐步重发，
不是任务描述本身。

## 三条使它只能当旁证的限制

1. **没有任何非 agent 基线。** 11 个模型跑的全是同一个 ReAct 脚手架，因此它**无法回答
   "这个任务是否需要 agent"**。
2. **步数与模型能力完全共线。** 没有固定模型只改执行粒度的实验，所以 (b) 只能说明"细粒度
   多步不是能力的代偿"，不能说明"批量执行导致了更好的结果"。
3. **单次运行、无方差。** −0.25pp 这类差值不可解读。
